#  Retail Sales Analysis — Excel Project

##  Project Overview

This project analyzes retail sales data using Microsoft Excel to understand sales performance, profitability, product categories, and other business trends.

The project demonstrates practical data analytics skills, including data cleaning, analysis, PivotTables, and data visualization.

##  Project Objectives

* Clean and prepare the retail sales dataset
* Analyze sales and profit performance
* Identify important sales trends and patterns
* Compare performance across different categories and regions
* Create meaningful visualizations for easier interpretation
* Present the analysis in a clear and professional Excel workbook

##  Data Cleaning

The dataset was reviewed and cleaned before analysis.

The cleaning process included:

* Checking for duplicate records
* Removing an identified duplicate record
* Reviewing the dataset for obvious data issues
* Verifying the cleaned data before analysis
* Refreshing PivotTables and visualizations after cleaning

##  Analysis

The analysis was performed using Excel PivotTables to summarize the retail sales data.

The workbook includes analysis of:

* Sales performance
* Profit performance
* Monthly sales and profit trends
* Product/category performance
* Regional performance
* Overall totals and comparisons

##  Dashoboard

Charts were created from the analysis to make important trends and comparisons easier to understand.

The dashboard section includes:

* Monthly Sales & Profit Trend
* Category/Product analysis
* Regional analysis
* Other key performance visualizations
